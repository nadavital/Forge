# Pain Extraction

When extracting pain:

1. Prefer repeated pain from multiple sources.
2. Preserve source URLs.
3. Mark unsupported claims as inference.
4. Favor MVP concepts that can be prototyped quickly.
5. Keep JSON valid and avoid comments, markdown inside string fields, or trailing commas.
